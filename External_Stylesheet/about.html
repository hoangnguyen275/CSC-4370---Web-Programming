About Messaging App - INSTANT

I created this web application named INSTANT because I wanted to build a simple messaging platform that focuses mainly on private communication. Unlike social media applications that include many different features, this application is designed primarily for sending and receiving messages between users.

One of my main motivations for creating this application is privacy. I want users to feel comfortable having conversations without worrying about third parties accessing or viewing their messages. The goal of this application is to create a more private communication environment where conversations are intended to stay between the people who are communicating.

I was also motivated to create this project because messaging applications are something people use every day.

Why This Design?

I chose blue and purple colors because they create a modern and trustworthy feeling that fits a communication application. The light background keeps the interface clean, while darker text colors make the content easier to read.
